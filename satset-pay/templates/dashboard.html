📱 Panduan Setting HP Android Listener (MacroDroid)

Langkah mudah menghubungkan notifikasi GoBiz / Shopee / DANA di HP ke VPS SATSET-PAY.

1. Install MacroDroid

Download aplikasi MacroDroid - Device Automation gratis dari Google Play Store di HP Android Anda.

2. Buat Makro Baru
  • Triggers: Pilih Notification ➔ Notification Received ➔ Centang aplikasi GoBiz, Shopee Partner, atau DANA.
  • Actions: Pilih Connectivity ➔ HTTP Request:
    Method: POST
    URL: http://{{ request_host }}:8088/api/v1/webhook/listener
    Content-Type: application/json
    Header: X-Webhook-Secret: {{ settings.webhook_secret }}
    Body (JSON):
    { "package": "[package_name]", "title": "[notif_title]", "body": "[notif_body]" }
3. Selesai!

Setiap ada pembeli yang transfer ke QRIS Anda, notifikasi di HP akan otomatis ditembakkan ke VPS dan invoice lunas seketika!
